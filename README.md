## Overview

Better BuildBuy significantly overhauls The Sims 4's build/buy catalog with a powerful search system that indexes object names, tags, and descriptions, multi-tag filtering to narrow down large categories, sort-by-price and sort-by-date-added options, and pack source labels on every item so you immediately know which expansion or stuff pack an object came from.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Better BuildBuy** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Full-Text Search** | Search object names, tags, and descriptions across the entire catalog |
| **Multi-Tag Filter** | Apply multiple category and style tags simultaneously to narrow results |
| **Sort Options** | Sort by price, date added, or item name ascending and descending |
| **Pack Labels** | Each catalog item shows its source pack with icon for quick identification |
